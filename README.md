doomscrollache — the headache you get from reading bad news you went looking for. A new English word for make.fun's "Invent a Word We Need" bounty: it names the ache that follows a doomscrolling session, the kind of small daily pain English never gave a name.

## Run it

```sh
node main.ts
```

The program writes the word and its one-line definition to `/output/entry.txt`.
